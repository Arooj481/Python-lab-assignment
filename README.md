# Python Lab Assignment

## Overview

This repository contains a Jupyter Notebook with five beginner-friendly
Python programs. The programs practice functions, loops, conditional
statements, lists, dictionaries, sets, user input, and file handling.

## Programs Included

### Q1: Student Result Management

-   Takes details for five students: name, roll number, and marks in
    Python, AI, and Maths.
-   Calculates each student's total marks, percentage, and grade.
-   Displays the results and identifies the student with the highest
    percentage.
-   Saves the results to `results.txt`.

**Grade criteria used in the code** - 80% or above: A - 70%--79.99%: B -
60%--69.99%: C - 50%--59.99%: D - Below 50%: F

The percentage is calculated using a maximum total of 300 marks.

### Q2: Sentence Analysis

-   Accepts a sentence from the user.
-   Counts words and characters.
-   Finds the longest and shortest words.
-   Counts English vowels (`a`, `e`, `i`, `o`, `u`, case-insensitive).
-   Displays unique words and the words sorted alphabetically.
-   Saves the analysis to `word_analysis.txt`.

### Q3: Shopping Bill

-   Accepts five products, including each product's name, price, and
    quantity.
-   Calculates each product's total price and the overall bill.
-   Applies a 10% discount when the total bill is greater than Rs.
    10,000.
-   Identifies the product with the highest unit price.
-   Saves the bill to `bill.txt`.

### Q4: Calculator

-   Performs addition, subtraction, multiplication, division, and
    modulus.
-   Uses separate functions for each operation.
-   Checks for division by zero.
-   Asks whether the user wants to perform another calculation.

### Q5: Restaurant Ordering System

-   Displays a menu containing burgers, pizza, fries, and drinks.
-   Lets the user select menu items and quantities.
-   Allows the user to enter `0` to finish ordering.
-   Displays the ordered items and total bill.
-   Saves the order details to `orders.txt`.

## Requirements

-   Python 3
-   Jupyter Notebook or JupyterLab

No third-party Python libraries are required; the programs use Python's
built-in features.

## How to Run

1.  Download or clone this repository.
2.  Open `Lab assignment.ipynb` in Jupyter Notebook, JupyterLab, or a
    compatible notebook environment.
3.  Run each question's cell separately.
4.  Enter the requested information in the notebook's input prompts.
5.  Output text files are created in the notebook's current working
    directory when the corresponding program is run.

**Important:** Q1, Q2, Q3, and Q5 write their results to text files. Run
the relevant cell before expecting those files to exist. Q4 continues in
a loop until you enter something other than `yes` when asked to
calculate again.

## Concepts Practised

-   Variables and data types
-   `input()` and `print()`
-   Conditional statements (`if`, `elif`, `else`)
-   `for` and `while` loops
-   Functions and return values
-   Lists, dictionaries, and sets
-   String operations and sorting
-   Finding maximum values
-   Basic arithmetic and percentage calculations
-   Reading and writing text files

## Notes and Input Limitations

-   Enter valid numeric values whenever the program asks for marks,
    prices, quantities, or menu item numbers.
-   Q2 expects a non-empty sentence because it accesses the first word
    to initialise the longest and shortest word.
-   In Q4, division by zero is handled, but modulus by zero is not
    handled separately.
-   The programs use the rules and menu prices written in the notebook;
    change those values in the code if your assignment requirements
    differ.
